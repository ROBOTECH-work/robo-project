What is Visual Basic 6.0 and its main features?
Click card or press SPACE to reveal answer
ANSWER
Visual Basic 6.0 is an event-driven programming language and integrated development environment (IDE) from Microsoft. Main features: Rapid Application Development (RAD), graphical user interface design, object-oriented programming (limited), database connectivity through ADO and DAO, and comprehensive debugging tools.
